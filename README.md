AI Image Generator - React Project

An AI-powered image generation web application built with React. This project allows users to generate AI images dynamically using API integration and display them instantly in the UI.

Features
Generate AI images from text prompts
Dynamic image rendering
React-based responsive UI
API integration for AI image generation
Real-time user input handling
Loading state management
Error handling for API requests
